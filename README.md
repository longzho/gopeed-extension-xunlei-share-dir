# 迅雷云盘下载扩展（只解析分享目录版）

这是 [cybdarlnig-png/gopeed-extension-xunlei](https://github.com/cybdarlnig-png/gopeed-extension-xunlei) 的 fork，改动只有一处主题：不再从分享根目录把所有文件夹递归读完，而是按分享链接里指向的目录去列。

原版遇到文件很多的分享时，会把整棵树列完才返回，容易超时。

## 改了什么

1. 读取并保留链接里的 `path` 参数。
2. 按目录名逐级向下，定位到链接指向的那个目录。
3. 从那里开始列内容，默认只列当前这一层。
4. 新增设置项「解析深度」：0 = 只当前目录（默认），1 = 再往下走一层，负数 = 旧版的全树递归。
5. 当前目录没有文件时，明确提示去调深度或者进子目录再复制链接。

其余逻辑、接口地址、请求头、登录凭证处理都和上游一致。

## 安装

把本仓库地址粘到 Gopeed「扩展」页的安装链接里。

注意：本仓库的扩展标识和官方版相同（`cybdarlnig-png@xunlei-pan`），装之前先移除市场里那个，否则会冲突。

## 用法

在浏览器里进入分享的某个子目录，地址会带上 `path`，整条复制给 Gopeed。带子目录路径的链接形如：

```
https://pan.xunlei.com/s/分享ID?pwd=提取码&path=/目录
```

如果只复制根目录链接，默认只会解析根这一层，里面只有文件夹、没有直接文件时，会提示你把解析深度改成 1 或更大。

## 凭证

Cookie 和 Authorization 需要来自同一个迅雷请求，分别填到扩展设置的两个输入框。本仓库不改这块逻辑，详细步骤见上游 README。
